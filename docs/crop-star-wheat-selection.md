# Terra Chronicle `crop_star_wheat` 定版决议

## 结论

`crop_star_wheat` 的最终首发基底选择为 **Candidate 02**。

## 选择理由

- 基础谷物身份清楚
- 幼苗与成熟态都可读
- 丰收感强，适合作为 Terra 的基础经济作物
- 星光魔法感存在但不过度，不会变成装饰品
- 可同时服务农场地块、库存图标与炼金材料

## 生产补充

可从其他候选借鉴：
- **Candidate 05**：田地生长阶段和 farm tile 呈现
- **Candidate 03 / Candidate 06**：库存、炼金、收获物图标变体

## 生产适配要求

正式落地时应保持：
- 明确的麦穗轮廓
- 幼苗 / 成熟 / 收获物三态差异
- 少量星形籽粒或星光点缀
- 暖金、草绿、土褐主色
- 不要像普通图库麦穗，也不要过度玩具化
