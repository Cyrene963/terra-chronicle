# Terra Chronicle 首发资产家族表

这份表是“先做哪些”的执行版。原则是：先少量做对，再批量扩展。

## 1. 卡牌家族

### 1.1 基础攻击家族
首发代表：
- `card_slash_sprout`：划击·新芽型
- `card_thorn_cut`：荆刺斩
- `card_burst_bloom`：绽放打击

用途：
- 作为所有攻击卡的基础语言
- 建立刃 / 芽 / 藤蔓的混合母题

### 1.2 基础防御家族
首发代表：
- `card_root_guard`：根甲
- `card_bark_shield`：树皮护盾
- `card_mist_ward`：雾幕护符

用途：
- 建立 Terra 的防御视觉体系
- 统一盾 / 根 / 甲 / 护符的表达

### 1.3 炼金与祝福家族
首发代表：
- `card_ember_pulse`：余烬脉冲
- `card_verdant_rite`：青芽仪式
- `card_terra_blessing`：大地祝福

用途：
- 作为战斗外成长与临时祝福的视觉入口
- 让奖励看起来像真正的“工坊产物”

## 2. 怪物家族

### 2.1 根系污染家族
首发代表：
- `monster_root_worm`：根虫
- `monster_vine_husk`：藤壳
- `monster_mold_bramble`：霉荆

用途：
- 作为普通敌人与生态污染的基础家族
- 与作物、根系、土壤形成直接视觉联系

### 2.2 孢子与菌群家族

- `monster_fungus_knight`：菌甲
- `monster_mist_mold`：雾菌

用途：
- 用于地城、湿地、阴影区域
- 适合做持续伤害与状态效果怪物

### 2.3 石壳与裂岩家族

- `monster_crack_shell`：裂壳

用途：

## 7. 首发顺序建议

如果要真正开画，建议按这个顺序：
1. `card_slash_sprout`
2. `monster_root_worm`
3. `beast_spring_drop`
4. `crop_star_wheat`
5. `ui_card_frame_terra`

原因：
- 这 5 个最能建立统一风格
- 能最快回流到战斗、农场、灵兽和工坊
- 对后续资产复用价值最高

## 8. 执行规则

以后每次新增一批资产时，只回答四个问题：
- 这批属于哪个家族？
- 首发代表是哪几个？
- 它们共享的视觉母题是什么？
- 先做哪个最能回流到游戏体验？

回答不出来，就先补家族表，不要直接开画。
