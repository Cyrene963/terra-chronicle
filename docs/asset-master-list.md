# Terra Chronicle 资产总表与制作优先级

这份清单配合 `docs/unified-art-design-spec.md` 使用。它回答的是：先做什么、做多少、怎么统一，而不是具体怎么画。

## A. 当前必须优先统一的资产

### A1. 战斗卡牌
优先级：最高
- 普通攻击卡
- 普通防御卡
- 恢复/祝福卡
- 炼金产物卡
- 稀有卡 / 事件卡

目标：
- 统一卡框语言
- 统一费用珠与中心图腾
- 统一稀有度/属性表达
- 统一描述区排版

### A2. 怪物
优先级：最高
- 普通污染怪
- 精英怪
- Boss 怪
- 地城特化怪

目标：
- 每个族群有强轮廓
- 普通怪与 boss 共享母题
- 污染方向和自然方向一致可识别

### A3. 灵兽 / 宠物
优先级：高
- 水系灵兽
- 火系灵兽
- 土系灵兽
- 风系灵兽
- 深渊系变体

目标：
- 一眼知道能做什么
- 可爱但不幼稚
- 进化分支看起来合理

### A4. 农作物
优先级：高
- 谷物类
- 根茎类
- 叶菜类
- 果实类
- 炼金素材类

目标：
- 幼苗、成熟、收获三态统一
- 作物本身就像可装备/可炼金的素材

## D. 制作顺序建议

### 第一阶段：可见度最高的核心资产
1. 战斗卡牌统一
2. 怪物统一
3. 灵兽统一
4. 农作物统一

### 第二阶段：辅助资产
5. 材料与掉落物
6. 地城节点图标
7. 状态与祝福图标

### 第三阶段：体验封装
8. 公用 UI 组件
9. 结算与转场演出
10. 图鉴 / 商店 / 预览层

## E. 每个资产的最低交付标准

所有资产交付前必须满足：
- 轮廓清楚
- 配色符合 Terra 方向
- 能嵌入现有羊皮纸 UI
- 不破坏统一审美
- 可在浏览器实际页面中验证

## F. 资产命名建议

建议按用途和族群命名，而不是按临时灵感命名：
- `card_...`
- `monster_...`
- `beast_...`
- `crop_...`
- `material_...`
- `ui_...`
- `status_...`
- `reward_...`

## G. 后续工作方式

当以后要新增一批内容时，先输出这三项：
1. 这批资产属于哪个类别
2. 这批资产的统一视觉母题是什么
3. 这批资产的最小交付列表是什么

如果三项说不清，就先不要画，先补设计。
