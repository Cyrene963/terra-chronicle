# Terra Chronicle 首发资产制作分镜说明

这份文档把首发资产拆到更接近制作层，方便直接进入绘制、生成或 UI 实作。

## 1. `ui_card_frame_terra`

### 结构分层
- 底层：旧纸/羊皮纸底材
- 中层：铜边与皮革装订感边框
- 上层：标题区、插画区、描述区、费用珠区
- 点缀层：角花、轻微磨损、微光金线

### 关键观感
- 卡框本体必须像一个被工坊打造出来的物件
- 视觉上要“稳”，不能像网页面板
- 不抢中间插画，但本身也要有工艺感

### 交付要点
- 先确定卡框比例
- 再确定内部分区
- 最后决定角花和细部装饰

## 2. `card_slash_sprout`

### 结构分层
- 背景层：羊皮纸底材
- 主体层：弯刃划开新芽的中心构图
- 辅助层：藤蔓、叶片、微光粒子
- UI 层：费用珠、标题、描述区、类型边框

### 关键观感
- 中心构图要一眼看懂是“攻击”
- 但攻击方式不是铁器，而是 Terra 世界里的生长斩击
- 画面重心应略偏中上，方便卡牌阅读

### 交付要点
- 先画中心构图，再适配卡框
- 再调整攻击感与植物感的平衡
- 最后统一色调和字体区

## 3. `monster_root_worm`

### 结构分层
- 主体层：根虫长躯干
- 头部层：根须角、裂口、孢子眼
- 皮肤层：泥壳、菌膜、腐根纹理
- 污染层：暗紫瘴气、裂纹亮边

### 关键观感
- 必须像从泥土中钻出来的怪物
- 远看只要轮廓就知道它危险
- 近看能感到植物/土壤/腐烂混合在一起

### 交付要点
- 先做强轮廓草图
- 再把根系特征塞进去
- 最后加污染感和细节层

## 4. `beast_spring_drop`

### 结构分层
- 主体层：小巧滴状身体
- 附属层：叶片尾鳍、透明流线、细小水光
- 表情层：明亮眼睛、亲切神态
- 功能层：农场感、浇灌感、辅助感

### 关键观感
- 是“会帮忙的可爱生物”，不是装饰品
- 要有透明、干净、轻盈的感觉
- 即便缩成面板小图标也能认出

### 交付要点
- 先保证剪影可识别
- 再加水感和叶感
- 最后微调亲和表情

## 5. `crop_star_wheat`

### 结构分层
- 幼苗层：初芽、细茎、刚露头的生长感
- 成熟层：穗粒、弯曲麦秆、星点微光
- 土壤层：根部与地表连接
- UI 层：收获图标、库存图标、种植图标

### 关键观感
- 幼苗和成熟态差别要很大
- 成熟后必须有“丰收感”和“工坊价值感”
- 既能放在田里，又能作为材料图标出现

### 交付要点
- 先定成熟态轮廓
- 再回推幼苗态
- 最后统一成 Terra 世界的基础农作物语言

## 6. 直接制作时的顺序建议

如果现在真的开始做，建议顺序：
1. `ui_card_frame_terra`
2. `card_slash_sprout`
3. `monster_root_worm`
4. `beast_spring_drop`
5. `crop_star_wheat`

原因：
- 卡框先统一，后面所有卡都省事
- 攻击卡和怪物最能快速建立战斗风格
- 灵兽和作物会自然回流到农场系统

## 7. 最终原则

首发资产不是要“单个都惊艳”，而是要“组合后像一个完整商业游戏”。
如果后续每个家族都照这个节奏扩展，Terra 的视觉语言就会稳定下来。
