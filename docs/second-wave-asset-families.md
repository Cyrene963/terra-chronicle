# Terra Chronicle 第二批资产家族表（扩展版）

这份表是首发五件套之外，最值得继续往下做的第二批家族。它们优先补齐战斗、农场、炼金、地城和资源体系。

## 1. 根茎作物家族

### 代表资产
- `crop_moon_turnip`：月萝
- `crop_iron_tuber`：铁薯
- `crop_moss_radish`：苔萝

### 家族定位
- 偏功能型作物
- 连接护甲、恢复、耐久、炼金和工坊升级

### 视觉关键词
- 地下根块
- 朴实
- 耐储存
- 土壤感
- 有重量

### 统一要求
- 幼苗小而稳，成熟块茎要有明显体积
- 形状要能一眼分出品种
- 与谷物家族形成“地上 / 地下”对照

## 2. 孢子与菌群怪物家族

### 代表资产
- `monster_spore_gnarl`：孢瘤
- `monster_fungus_knight`：菌甲
- `monster_mist_mold`：雾菌

### 家族定位
- 地城/湿地/阴影区域核心怪物群
- 主打持续状态、毒、腐蚀、雾化、孢子扩散

### 视觉关键词
- 菌盖
- 孢粉
- 雾气
- 黏膜
- 异化生长

### 统一要求
- 轮廓要能看出菌类或孢子来源
- 不能做成普通亡灵或普通魔法怪
- 颜色以灰绿、暗紫、病白为主

## 3. 火系灵兽家族

### 代表资产
- `beast_forge_ember`：炉火兽
- `beast_cinder_mane`：灰鬃兽
- `beast_sun_kiln`：日窑兽

### 家族定位
- 工坊与炼金核心劳动力
- 提升熔炉、烘焙、锻造、温度类系统表现

### 视觉关键词
- 炉火
- 铜暖
- 灰烬
- 陶窑
- 火星

### 统一要求
- 不是单纯红色怪兽
- 身体结构要体现“耐热、燃烧、持续加温”
- 发光区域应集中在角、背脊、鬃毛或核心腔

## 4. 基础材料家族

### 代表资产
- `material_wood_raw`：原木
- `material_stone_chip`：石屑
- `material_iron_frag`：铁片

### 家族定位
- 全系统经济与合成底层
- 卡牌、建筑、升级、炼金、工坊都需要

### 视觉关键词
- 原始
- 朴素
- 有真实材质
- 适合做图标和库存格子

### 统一要求
- 单图标也要能认出材质来源
- 不要做得太精致导致不像基础材料
- 要和 UI 背景形成足够对比

## 5. 地城节点 UI 家族

### 代表资产
- `ui_dungeon_node_combat`
- `ui_dungeon_node_elite`
- `ui_dungeon_node_rest`
- `ui_dungeon_node_shop`
- `ui_dungeon_node_boss`

### 家族定位
- 地城地图上的信息入口
- 用节点状态直接告诉玩家风险与收益

### 视觉关键词
- 地图节点
- 金环
- 阴影
- 路线分歧
- 可选性

### 统一要求
- 战斗 / 精英 / Boss 的层级感必须非常清楚
- 休息与商店要有安定感
- 节点图标要和 Terra 世界母题一致，而不是系统默认图标

## 6. 状态与祝福图标家族

### 代表资产
- `status_shield`：护甲
- `status_energy`：能量
- `status_blessing`：祝福
- `status_weakness`：弱点
- `status_corruption`：污染
- `status_thorns`：荆棘

### 家族定位
- 战斗 HUD 的语义基础
- 让玩家不用读字也能懂状态变化

### 视觉关键词
- 小而清楚
- 一眼识别
- 与卡框一致
- 可做 HUD 复用

### 统一要求
- 图标必须简洁
- 不要过度复杂细节
- 必须能缩小到 24px 仍保持可读性

## 7. 第二批制作顺序

如果现在继续做，建议顺序：
1. `ui_dungeon_node_combat`
2. `status_shield`
3. `crop_moon_turnip`
4. `monster_spore_gnarl`
5. `beast_forge_ember`
6. `material_wood_raw`

原因：
- 先补地城和 HUD，可立刻回流到游戏中
- 作物和怪物能直接增强农场/战斗循环
- 材料类能把库存和工坊串起来

## 8. 结论

第二批资产的目标不是单独炫技，而是把第一批首发资产没有覆盖的系统补齐，让 Terra 的闭环更完整、更像成品游戏。
