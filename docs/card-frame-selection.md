# Terra Chronicle 卡框定版决议

## 结论

`ui_card_frame_terra` 的最终首发基底选择为 **Candidate 01**。

## 选择理由

- 结构最清楚：标题区、插画区、描述区、费用珠区都足够明确
- 与现有暖羊皮纸 + 青铜风格最匹配
- 小尺寸可读性最好
- 作为战斗卡牌的标准壳最稳，能兼容后续大部分攻击卡、防御卡、祝福卡
- 既有手工工艺感，也不会太乱

## 生产适配要求

后续正式卡框落地时，应保持以下特征：
- 左上角费用珠必须保留高对比度
- 中央插画窗必须清晰、留白充足
- 底部描述区必须稳定可读
- 整体不加过多噪点装饰
- 保持 warm parchment + bronze + handcrafted fantasy 的主方向
