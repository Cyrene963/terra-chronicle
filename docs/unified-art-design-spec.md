# Terra Chronicle 统一美术与内容设计规范

## 1. 文档目标

这份文档是 Terra Chronicle 的统一设计母版。所有怪物、卡牌、宠物、农作物、道具、UI 面板、图标、特效和宣传图，都必须先对齐这里的规则，再进入具体制作。

目标不是“画得好看”而已，而是让整个项目在任何页面、任何资产、任何战斗场景里都表现为同一款游戏，避免风格散、审美跳变和临时发挥。

## 2. 总体审美方向

当前项目的正式美术方向：
- 温暖奇幻
- 手账感 / 羊皮纸感
- 自然农场与深渊污染的对照
- 轻微中世纪炼金气质
- 具有商业游戏级的层次、质感和统一性

核心感受应该是：
- 看起来像一款完整成品，而不是网页 demo
- 细节丰富，但不杂乱
- 温暖、神秘、可信、可长期扩展
- 有手工感，但不过度卡通化

## 3. 世界观视觉母题

Terra 的视觉母题只有一套主轴：
- 自然、土地、作物、灵兽、工坊、炼金、深渊污染
- 所有内容都应该能看出“从土地生长出来”
- 所有怪物、卡牌、宠物、作物，最好都能解释为同一世界生态链的不同侧面

可反复使用的符号：
- 土壤纹理
- 种子 / 芽 / 叶 / 果实
- 木纹 / 石纹 / 铜纹 / 皮革 / 羊皮纸
- 金色边框与微光
- 污染瘴气、裂纹、暗紫烟雾、苔藓、孢子
- 四季气候变化

## 4. 统一设计原则

所有资产必须同时满足以下四点：
1. 一眼可识别用途
2. 远看轮廓清楚，近看细节耐看
3. 风格统一，能和现有羊皮纸 UI 共存
4. 能在农场、卡组、地城、灵兽面板之间复用视觉语言

## 5. 卡牌设计规范

### 5.1 卡牌定位
卡牌不是纯数值方块，而是“从作物、材料、炼金结果中长出来的战斗媒介”。

### 5.2 外观结构
每张卡都建议包含：
- 顶部名称
- 核心图腾 / 插画中心图标
- 中部功能象征（刃、盾、芽、火、风、水、土等）
- 底部效果描述
- 左上角费用珠
- 边框颜色体现类型

### 5.3 风格要求
- 底材：羊皮纸、皮革、铜版、旧纸、木板感
- 图标：尽量使用具象符号，而不是纯 emoji
- 色调：暖金、土黄、青铜、暗红、苔绿、灰蓝
- 质感：微旧、微磨损、但精致

### 5.4 类型映射
- 攻击卡：刃、刺、爆裂、藤蔓、冲击、灼烧
- 防御卡：盾、甲、根、茧、岩层、护符
- 恢复卡：芽、露、水滴、药草、果实
- 特殊卡：炼金、召唤、祝福、地脉、季节、共鸣

### 5.5 禁止事项
- 纯黑白极简不适合 Terra 的卡牌主体
- 不要用廉价科技感蓝紫霓虹覆盖整套卡
- 不要每张卡都用完全不同的边框语言

## 6. 怪物设计规范

### 6.1 怪物定位
怪物不是随机敌人，而是“生态链失衡、土地污染、深渊侵蚀”的具体化。

### 6.2 设计来源
怪物应尽量来自以下来源：
- 灵兽的污染变体
- 作物/植物的异化形态
- 土地、矿物、菌类、虫群、苔藓、树根、岩层的拟生物化
- 深渊能量对自然生态的扭曲结果

### 6.3 轮廓原则
- 远看轮廓必须强
- 每个怪物要有一个主形状识别点：角、冠、壳、根须、藤臂、孢子团、裂石躯干等
- 轮廓不要过度写实到丢失游戏性

### 6.4 颜色原则
- 普通生态怪：土黄、橄榄绿、褐色、木色、灰石色
- 污染怪：暗紫、赤黑、病绿、烟灰
- 精英 / boss：更强对比、更高发光、更复杂层次，但不能脱离 Terra 母题

### 6.5 怪物家族建议
- 根系系：树根、藤蔓、菌丝、地脉
- 虫群系：甲壳、孢子、裂壳、飞虫
- 石壳系：岩、矿、结晶、结界
- 污染系：瘴气、裂纹、黑化叶片、畸变芽

## 7. 宠物 / 灵兽设计规范

### 7.1 灵兽定位
灵兽必须让人感觉是“土地上的活生物资产”，既可爱又有生产功能。

### 7.2 设计重点
- 轮廓可爱，但不幼稚
- 有明确生态属性：水、火、风、土、木、金、月、影等
- 既能战斗，又能帮农场劳动
- 每只灵兽都应有“功能辨识度”

### 7.3 造型要求
- 身体结构简洁，便于做进化分支
- 面部情绪清楚，眼神有生命感
- 背部、尾部、角、翅、壳、鬃毛等部位可作为成长变化区
- 进化时要有“变得更有能力”而不是单纯变大

### 7.4 灵兽系列建议
- 水系：清澈、流动、雾气、晶亮
- 火系：炉火、熔光、暖铜、火星
- 土系：根、石、苔、种子、岩甲
- 风系：羽毛、风铃、叶片、轻盈线条
- 深渊系：污染、裂纹、暗色孢子、异化边缘

## 8. 农作物设计规范

### 8.1 农作物定位
农作物不仅是资源，而是“生长中的卡牌与世界材料”。

### 8.2 农作物风格
- 先可爱，再写实
- 每种作物都有鲜明的形状记忆点
- 要能被玩家一眼认出“这是哪种作物”
- 成熟态与幼苗态要有强对比

### 8.3 作物类别建议
- 谷物类：麦、稻、黍、穗类
- 根茎类：萝卜、薯类、根块
- 叶菜类：叶片、卷叶、茎秆
- 果实类：浆果、果球、果荚
- 炼金素材类：发光植物、药草、菌菇、种子晶体

### 8.4 视觉要求
- 幼苗要有“芽感”
- 成熟作物要有饱满度与可采摘感
- 少做过度卡通贴图感，多做自然层次和光泽

## 9. UI 与图标统一规范

### 9.1 总原则
UI 必须像一套完整游戏系统，而不是临时拼的网页组件。

### 9.2 统一语言
- 羊皮纸、金边、铜扣、木牌、玻璃、发光符文
- 面板层级清晰，主次分明
- 重要交互必须有明显反馈

### 9.3 图标要求
- 统一线条粗细或统一材质风格
- 重要图标最好做成 Terra 定制图标，不直接依赖 emoji
- 资源、状态、元素、祝福、地城节点都应有一致图标语言

## 10. 色彩与材质规范

### 10.1 基础色系
- 土地：棕、褐、土黄
- 农场：暖绿、草绿、浅金
- 工坊：青铜、铜金、陶土
- 地城：暗紫、深蓝、黑石、旧金
- 祝福：金、暖白、微绿
- 污染：黑紫、赤黑、病绿

### 10.2 材质优先级
优先使用：
- 纸张
- 皮革
- 木头
- 铜金属
- 石材
- 叶片
- 发光孢子

避免：
- 过亮塑料感
- 过平扁平化贴图
- 过于赛博朋克霓虹

## 11. 内容生产流程

所有新内容都按以下顺序走：
1. 先写设计目标
2. 再定视觉母题
3. 再定轮廓与材质
4. 再定颜色与稀有度
5. 再做 UI / 卡面 / 图标适配
6. 最后进战斗、农场或商店系统

如果要生成大量 AI 图：
- 先出少量参考方向
- 选定统一母版
- 再批量生成
- 最后只能用与 Terra 当前素材兼容的方案

## 12. 具体资产的统一要求

### 怪物
- 有生态来源
- 有清晰轮廓
- 有污染/自然两种方向的区分

### 卡牌
- 有清晰类型
- 有统一卡框语言
- 有费用珠与中心图腾

### 宠物 / 灵兽
- 可爱但不幼稚
- 功能可辨识
- 进化后视觉上更“有用”

### 农作物
- 一眼能认出种类
- 成熟态有收获欲望
- 能自然连接炼金和卡牌系统

### 道具 / 材料
- 具有手工制品感
- 适合作为工坊输入或奖励掉落

## 13. 禁止项

以下内容除非非常特殊，否则不要进入 Terra 主视觉：
- 低质 emoji 堆叠
- 纯 AI 风格漂浮抽象图，没有明确功能识别
- 不统一的二次元贴图拼接
- 赛博朋克霓虹过强
- 过度写实导致失去游戏感
- 临时做法不回收成统一体系

## 14. 最后原则

任何新资产都要先回答三个问题：
1. 它属于 Terra 哪个生态层？
2. 它和现有羊皮纸手账风怎么统一？
3. 它能否复用到卡牌、UI、图鉴、商店或战斗演出里？

如果答案不清楚，就先别画，先定规范。
