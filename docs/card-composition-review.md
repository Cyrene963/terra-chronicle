# Terra Chronicle 卡牌组合预览评审

## 评审对象

- 卡框：`ui_card_frame_terra_candidate_01`
- 插画：`card_slash_sprout_candidate_01`
- 组合预览：`assets/generated/composited-cards/card_slash_sprout_preview.png`

## 结论

方向成立，但暂不直接接入 `src/battle.js`。

## 成立的部分

- 卡框与新芽斩击插画的世界观一致
- 暖羊皮纸、青铜、植物、金色斩击的 Terra 感明确
- 作为收藏型/正式卡牌方向，质感明显高于当前 DOM 占位卡
- 攻击身份清楚，适合作为基础攻击卡样板

## 暂不接入的原因

- 顶部费用珠与标题区域拥挤
- 标题可读性不足
- 插画区域像贴图叠加，尚未与卡框融合
- 规则文本区域留白和层级还不理想
- 在小尺寸手牌中可能过于繁复，影响战斗快速阅读

## 后续适配规则

正式进入游戏前必须做一版专门的 UI 适配：
1. 卡框背景保留，但标题区必须更平整
2. 费用珠与标题区必须分离
3. 插画区必须裁切成内嵌窗口，而不是直接贴图
4. 规则文本区需要更高对比、更稳定排版
5. 手牌小尺寸下仍必须能读出费用、名称、类型、效果
