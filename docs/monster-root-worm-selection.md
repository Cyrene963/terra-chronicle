# Terra Chronicle `monster_root_worm` 定版决议

## 结论

`monster_root_worm` 的最终首发基底选择为 **Candidate 04**。

## 选择理由

- 根虫身份最清楚：有虫形躯干、根系结构、树皮质感
- 作为普通污染怪可读性最好，远看轮廓也成立
- 紫色污染明确但不过度，不会变成纯恶魔或亡灵
- 适合后续改成 2D 战斗精灵
- 与 Terra 的农场生态失衡主题最贴合

## 生产补充

可从 **Candidate 03** 借鉴：
- 弱点位置
- 钻地/突袭动作
- 尺寸参考
- 精灵化时的侧面姿态

## 生产适配要求

正式落地时应保持：
- 强根系轮廓
- 明确头部/口器/根须角
- 土壤、树皮、菌膜材质
- 少量紫色污染裂纹与瘴气
- 不要变成普通虫子、恶魔、骷髅或科幻怪物
