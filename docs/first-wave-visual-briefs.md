# Terra Chronicle 首发资产视觉 Brief

这份文档用于把首发家族直接推进到可制作状态。它不是最终成图，而是每个资产的统一制作说明。

## 1. card_slash_sprout

### 目标
这张卡要成为 Terra 战斗卡牌的样板：一眼能看出是攻击卡，同时带有“作物生长、土地回响、藤蔓斩击”的 Terra 味道。

### 关键词
- 攻击
- 新芽
- 刃光
- 藤蔓
- 青铜与羊皮纸

### 视觉构成
- 牌面：羊皮纸或旧纸底材，带青铜边框
- 中心图腾：一株刚冒芽的植物被弯刃切开，形成动势
- 主色：暖金、苔绿、浅土黄
- 费用珠：铜金色，左上角高辨识度
- 标题字体：衬线体，稳重、清晰

### 情绪
- 干净
- 有力量
- 不是纯武器卡，而是“生长中的攻击”

### 禁止
- 不要太机械
- 不要赛博霓虹
- 不要复杂到看不出是攻击卡

## 2. monster_root_worm

### 目标
这是普通污染怪的基础样板：它要看上去像“根系被污染后长出的虫形生物”，并且能和农场/土地主题直接挂钩。

### 关键词
- 根系
- 污染
- 虫躯
- 土壤
- 蛀蚀

### 视觉构成
- 主轮廓：长条、弯折、像根也像虫
- 头部识别点：有根须角、裂纹口器或孢子眼
- 材质：泥土、木质、菌膜、暗色苔藓
- 主色：褐色、橄榄绿、暗紫污染点缀

### 情绪
- 可怖但不是血腥
- 明显是生态失衡的产物
- 像是“从土地里爬出来的坏东西”

### 禁止
- 不要做成纯昆虫怪
- 不要做成纯骷髅或纯恶魔
- 不要丢失根系来源

## 3. beast_spring_drop

### 目标
它是水系首发灵兽，要有“会照顾农田”的感觉，像小小的春天精灵或露滴守护者。

### 关键词
- 水系
- 露珠
- 春天
- 流动
- 温柔

### 视觉构成
- 轮廓小巧，便于做宠物/灵兽面板
- 身体有水滴、叶片、透明质感或流线形尾部
- 眼神明亮，表情亲和
- 主色：清蓝、浅绿、晶白

### 情绪
- 亲切
- 柔软
- 有劳动价值
- 一眼就知道是“会帮农场”的灵兽

### 禁止
- 不要做成普通小鱼或普通水元素
- 不要过度幼儿化
- 不要丢失灵兽的功能感

## 4. crop_star_wheat

### 目标
它是 Terra 的基础经济作物代表，必须让玩家一眼就想收割、想种植、想用于炼金和卡牌。

### 关键词
- 谷物
- 丰收
- 星光
- 土地
- 基础资源

### 视觉构成
- 幼苗态：小小芽点，清楚有“种出来了”的感觉
- 成熟态：麦穗饱满，带微微发光或星点质感
- 主色：金黄、草绿、土褐
- 形状要有明显的穗形轮廓

### 情绪
- 有希望
- 有收成感
- 是整个经济循环的开端

### 禁止
- 不要像普通图库麦穗
- 不要太写实导致不适配 UI
- 不要没有成熟/幼苗差异

## 5. ui_card_frame_terra

### 目标
这不是普通边框，而是 Terra 全局卡面语言的标准件。

### 关键词
- 羊皮纸
- 金边
- 铜扣
- 装订
- 手工质感

### 视觉构成
- 主体像一张被工坊加工过的实体卡
- 有统一的费用珠位置
- 有统一的标题区、插画区、描述区
- 边缘略旧、略磨损，但高级

### 情绪
- 成品感
- 工艺感
- 可复用

### 禁止
- 不要纯平 UI 框
- 不要浮夸霓虹边
- 不要每张卡再单独改结构

## 6. 执行建议

如果要实际开画，建议顺序如下：
1. `ui_card_frame_terra`
2. `card_slash_sprout`
3. `monster_root_worm`
4. `beast_spring_drop`
5. `crop_star_wheat`

原因：
- 先把“壳”统一，再画内容，后续资产最省力
- 卡框一统一，怪物/灵兽/作物很快就能被装进去
- 这是最接近“一步到位”的路线
