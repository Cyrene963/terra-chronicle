# Terra Chronicle 美术风格 Reference Cluster 体系

**版本**: v1.0  
**创建日期**: 2026-06-17  
**目的**: 统一视觉风格，确保所有美术资产符合统一的艺术方向

---

## 为什么需要 Reference Cluster？

当前问题:
- AI 生成的素材风格不统一（有些手绘风、有些写实风、有些卡通风）
- 缺少明确的艺术方向定版
- 新素材容易偏离已有资产的视觉语言

解决方案:
- 建立 4 个核心 cluster，每个 cluster 包含 3-5 张风格统一的参考图
- 所有新素材必须基于对应 cluster 进行"图生图"或"参考图延续"
- 禁止跨簇混搭（例如不能用写实风的树木 + 卡通风的房屋）

## Cluster 1: 环境与地表 (Environment & Terrain)

**风格定义**: Soft painterly / Hand-painted 2D / 温暖自然

### 核心参考图 (待收集)
1. **草地瓦片**: 手绘笔触，色块过渡自然，绿色饱和度适中
2. **树木**: 扁平 2D 轮廓，叶簇分层明显，暖色调树干
3. **水面**: 流动感笔触，蓝绿色调，岸边柔和过渡

### 关键特征
- **笔触**: 可见的手绘笔触，非照片级写实
- **色调**: 暖色偏黄绿，避免冷灰或纯黑
- **细节密度**: 中等，远看形态清晰，近看有纹理但不繁琐
- **光影**: 柔和渐变，非硬边缘

### 应用资产
- 草地/土壤/沙地瓦片
- 树木 (橡树/樱树)
- 灌木/岩石
- 耕地/桥梁

### 禁止风格
- ❌ 像素风 (Pixel art)
- ❌ 硬边缘卡通 (Flat vector)
- ❌ 3D 渲染风格
- ❌ 照片写实

## Cluster 2: UI 与面板 (Interface & Panels)

**风格定义**: 奇幻羊皮纸手账风 / 暖色衬线字体 / 金色装饰

### 核心参考图 (待收集)
1. **羊皮纸背景**: 沙色渐变，纸张纹理，温暖质感
2. **金色边框**: 细线装饰，四角 L 形纹饰，不过度华丽
3. **按钮**: 内嵌式，柔和高光，深棕色边框

### 关键特征
- **色调**: `#f4ecd8` (羊皮纸) + `#d4af37` (金色) + `#2a2520` (深墨)
- **字体**: Cormorant Garamond (英文) + Noto Serif SC (中文)
- **纹理**: 纸张纤维可见，轻微污渍/磨损感
- **装饰**: 对称几何，古典图案，避免现代感图标

### 应用资产
- 炼金大釜 UI
- 地城地图面板
- 升级/培育面板
- 卡牌模板

### 禁止风格
- ❌ 现代扁平化 (Material Design)
- ❌ 科技感玻璃拟态
- ❌ 霓虹发光边框
- ❌ 纯色背景无纹理

## Cluster 3: 生物与灵兽 (Creatures & Beasts)

**风格定义**: 奇幻生物插画 / 柔和轮廓 / 魔法元素点缀

### 核心参考图 (待收集)
1. **水灵兽**: 半透明身体，流水纹理，蓝色光晕
2. **火灵兽**: 暖色渐变，火焰装饰，橙红色调
3. **神社狐灵**: 白色主体，金色装饰，飘逸尾巴

### 关键特征
- **轮廓**: 柔和曲线，无锐利直线
- **材质**: 半透明/发光/流体感，非实体毛发
- **配色**: 元素色为主 (水=蓝绿，火=橙红，土=棕黄)
- **装饰**: 符咒/纹样/光点，增加奇幻感

### 应用资产
- 水/火/风/土灵兽
- 神社狐灵/御鹿幼灵/白蛇社灵/深海贵族
- 地城敌人 (根蚀虫等)

### 禁止风格
- ❌ 写实动物照片风格
- ❌ 怪兽猎人级精细渲染
- ❌ Chibi Q 版大头身
- ❌ 机械科技风格

## Cluster 4: 植被与作物 (Plants & Crops)

**风格定义**: 手绘植物插画 / 分层叶片 / 生长感

### 核心参考图 (待收集)
1. **星麦作物**: 金黄色麦穗，发光星点，3 阶段生长
2. **露莓作物**: 深蓝果实，绿色叶片，藤蔓缠绕
3. **树木叶簇**: 分层色块，边缘高光，四季差异明显

### 关键特征
- **叶片**: 分层叠加，边缘柔和，非单一色块
- **生长**: 幼苗→生长→成熟，尺寸和细节递增
- **配色**: 自然绿色，成熟作物带暖色 (金黄/深蓝)
- **细节**: 叶脉/果实高光/露珠点缀

### 应用资产
- 星麦/露莓作物
- 树木叶簇 (春夏秋冬)
- 灌木
- 草叶细节

### 禁止风格
- ❌ 像素风作物 (Stardew Valley)
- ❌ 3D 渲染植物
- ❌ 纯色填充无细节
- ❌ 科幻植物 (发光/金属质感)

## 使用流程

### 1. 新素材需求分类
确定素材属于哪个 cluster (环境/UI/生物/植被)

### 2. 查找 cluster 参考图
从对应 cluster 的 3-5 张参考图中选择最接近的 1-2 张

### 3. 图生图 / 参考延续
- **AI 生成**: 使用参考图作为"风格参考"或"图生图"输入
- **手绘**: 严格遵循 cluster 的关键特征

### 4. 质量检查
- ✅ 轮廓清晰，透明背景干净
- ✅ 色调与 cluster 一致
- ✅ 细节密度与现有资产匹配
- ✅ 在实际游戏尺寸下可读

### 5. 拒绝跨簇混搭
- ❌ 不允许: 手绘风树木 + 写实风作物
- ❌ 不允许: 奇幻UI + 现代扁平按钮
- ✅ 允许: 同一 cluster 内的细微风格差异

## 下一步行动

1. **收集参考图**: 从现有最佳资产中提取 12-20 张参考图
2. **分类整理**: 放入 `assets/reference_clusters/` 目录
3. **文档记录**: 为每张参考图标注"关键特征"和"适用场景"

1. **批量替换**: 将当前占位符/风格不统一资产按 cluster 重做
