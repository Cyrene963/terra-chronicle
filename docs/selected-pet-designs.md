# Terra Chronicle 首批精选宠物设定

本记录对应已接入的四只 first-playable 宠物：神社狐灵、御鹿幼灵、白蛇社灵、深海贵族。它们都必须使用透明 RGBA sprite；不得把带背景、场景、卡框、黑底、灰底或方形概念图直接放进游戏。

## 共同落地规则

- 资产路径：`assets/sprites/beast_*.png`
- 当前形态：first-playable companion sprite
- 场景位置：农场/孵化阵附近可见
- 接入层级：`src/main.js` 的 `ASSETS`、`normalizeBeasts()`、`companionPets`
- 验证：`tools/terra_visual_smoke.js` 检查 roster 与 scene companion

## 神社狐灵

- 文件：`assets/sprites/beast_shrine_fox_spirit.png`
- 元素：spirit / wind
- 视觉关键词：神社狐、符纸、叶尾、青绿灵火、红绳结
- 农场定位：侦察与预警型灵兽
- 被动：`狐火巡界` —— 每天降低一次突发虫害/污染事件触发率，并提高稀有资源发现率。
- 主动：`御札标记` —— 标记一块地，下一次收获有概率额外获得“灵符残片”材料，用于符咒类卡牌。
- 战斗作用：开局给一张临时“狐火闪避”牌；偏控制/闪避。
- 进化分支：
  - 巡界狐：强化侦察与稀有事件发现。
  - 御札狐：强化符咒卡与净化效果。
  - 稻荷狐：强化作物额外产出与市场收益。
- 动作语言：轻快小跳、尾巴左右摆、符纸微漂、偶尔狐火脉冲。

## 御鹿幼灵

- 文件：`assets/sprites/beast_sacred_fawnling.png`
- 元素：earth / light
- 视觉关键词：幼鹿、枝角、花叶纹、铃饰、柔金灵光
- 农场定位：土壤与成长祝福型灵兽
- 被动：`鹿鸣丰壤` —— 提高附近地块肥力恢复速度，降低连续耕种带来的土壤衰退。
- 主动：`踏青祝福` —— 让一片 3×3 地块获得一次成长加速，并微量提高收获品质。
- 战斗作用：生成防御/治疗类灵契牌，适合续航构筑。
- 进化分支：
  - 林冠鹿：强化范围肥力与生态稳定。
  - 晨露鹿：强化治疗和净化。
  - 祭铃鹿：强化季节事件奖励与团队辅助。
- 动作语言：温柔呼吸、前蹄轻点、耳朵/枝角抬动、周围光点缓慢环绕。

## 白蛇社灵

- 文件：`assets/sprites/beast_white_serpent_shrine.png`
- 元素：water / spirit
- 视觉关键词：白蛇、鸟居小冠、红绳、符纸、青绿鳞光
- 农场定位：水脉净化与病害控制型灵兽
- 被动：`社泉守护` —— 降低高湿地块的病害与虫害惩罚，把部分湿度转化为生态分。
- 主动：`蛇行净流` —— 沿河道/水渠释放净化波，清理污染孢子并给水系卡牌提供材料。
- 战斗作用：偏净化、护盾和持续治疗，可移除负面状态。
- 进化分支：
  - 社泉蛇：强化灌溉与水质净化。
  - 白虹蛇：强化战斗净化/护盾。
  - 神乐蛇：强化祭祀、符纸、季节仪式收益。
- 动作语言：连续蛇形摆动、身体轻微盘绕、头冠上下点动、符纸随水流飘。

## 深海贵族

- 文件：`assets/sprites/beast_deepsea_noble.png`
- 元素：water / moon
- 视觉关键词：瓷白、冰蓝、深海军蓝、少量金色、透明水流丝带、珍珠、蓝宝石、泡沫、水晶、贵族感
- 农场定位：高级水系灌溉与灵脉调律型灵兽
- 被动：`潮汐礼仪` —— 水系灵兽群总等级视作额外提高，湿润地块产出的露莓/水系材料品质上限提升。
- 主动：`蓝宝石潮声` —— 召唤一圈潮汐泡沫，短时间内让周围水系作物成长加速，并为下一张水系卡增加“潮汐”词条。
- 战斗作用：水系核心辅助，提供治疗、抽牌或能量返还；适合围绕“河川祝福”扩展构筑。
- 进化分支：
  - 珍珠侍从：强化低成本灌溉和成长加速。
  - 蓝宝石公爵：强化水系卡牌词条与战斗辅助。
  - 月潮王裔：强化灵脉、月相、季节事件和稀有材料产出。
- 动作语言：悬浮漂移、水流丝带摆动、泡泡周期浮起、身体像潮汐一样缓慢伸缩。
