# Terra Chronicle `beast_spring_drop` 定版决议

## 结论

`beast_spring_drop` 的最终首发基底选择为 **Candidate 04**。

## 选择理由

- 水滴身体最明确
- 农场浇灌/辅助功能感最强
- 亲切但不过度幼儿化
- 小尺寸轮廓稳定，适合未来做宠物图标或精灵
- 与 Terra 的农场经营主题最直接挂钩

## 生产补充

可从 **Candidate 01** 借鉴：
- 更清楚的脸部可读性
- 水滴尖端/小触角细节
- 更紧凑的 icon 化轮廓

## 生产适配要求

正式落地时应保持：
- pear-shaped 水滴身体
- 叶片披肩/叶片尾部
- 温和明亮表情
- 浇灌/春露/田间助手的功能感
- 不要变成鱼、普通水元素或玩具吉祥物
